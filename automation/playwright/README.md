# ShopLens Playwright Automation

## Purpose

This folder contains Playwright automation coverage for ShopLens web workflows. 
The goal is to validate key web user flows through repeatable UI automation and support regression testing during release cycles.

## Current Automation Coverage

- Web application launch
- User login flow
- Navigation to target feature area
- Basic UI validation
- End-to-end validation for one completed web scenario

## Tool

- Playwright
- TypeScript/JavaScript
- GitHub for version control

## Future Scope

- Additional web regression flows
- Product search validation
- Image upload/product scan flow if available on web
- Shopping list validation
- Negative login scenarios
- Cross-browser testing
- GitHub Actions CI execution

## Note

Current ShopLens voice chatbot testing is focused on Android and iOS mobile apps. Playwright is used for web automation. For native mobile chatbot automation, Appium or Flutter integration tests are recommended.
