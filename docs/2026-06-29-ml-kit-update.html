ML Kit On-Device Routing
▸
Confidence-based route split Live scan taps → /identify (skip full Gemini detection). Low-confidence & "Scan All" → /analyze. 38 MLKIT events logged via observability we added.
⚡
/identify skips Gemini detection ML Kit already localized the object. Gemini used only for crop description (if IDENTIFY_SKIP_GEMINI=false). Full bounding-box detection pass eliminated.
🔒
Double-tap crash fixed _identifying guard ignores second tap while capture is in-flight — prevented crash on already-stopped camera stream.
🔗
End-to-end observability Mobile sends route, confidence, objects, labels to backend on every tap. Logged as MLKIT | lines, correlated by req= ID.
MLKIT | route=identify trigger=tap

IDENTIFY_SKIP_GEMINI (default: true)
✓
Active on 100% of post-fix requests All 24 requests after Jun 28 03:31 deploy show "Gemini description skipped" in logs. Zero regressions.
⏱
Saves 3–6s per tap (confirmed) Avg response dropped from 12.2s → 5.2s on requests where Lens succeeded. Gemini call eliminated from hot path.
↺
Exception: Lens timeout recovery When Lens times out, Gemini runs as a recovery step to generate a Shopping query. Seen on 4 requests (18–25s range). Set IDENTIFY_SKIP_GEMINI=false to always enable.
Lens Timeout & Quota Defense
⏱
LENS_TIMEOUT_SECONDS: none → 8 → 12 Same day evolution visible in logs. Timeout=25 (old lib default) → 8s cap → raised to 12s after seeing a 7.87s valid response get cut off.
📡
SerpAPI quota probe before recovery 3s account check before Gemini+Shopping chain. If quota exhausted → return immediately. Worst case: 15s (was 37s unrecoverable hang).
🛒
Shopping fallback on timeout Lens timeout now triggers Gemini recovery → Shopping. 3/4 timeout requests returned results this way. Was silently returning 0 results.
Cache & Correctness
◎
Perceptual hash replaces SHA-256 SHA-256 never hit for live scan — each camera frame differs by bytes. 8×8 average hash matches same object across minor crop/scale differences.
SHA-256: 0% hitavg-hash: same object = cache hit
🔢
Search limit fixed on /identify max_searches_per_run only forwarded to /analyze. Fixed 3 gaps in chain: provider, use-case signature, _google_lens call site.
